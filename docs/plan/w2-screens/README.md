# W2 화면 사진 — 새 시안의 어법으로 다시 세운 홈과 아래 탭 바

> 한 줄 요지: **이 폴더의 다섯 장은 2026-09-18 의 W2 슬라이스 A 가 만든 화면을 실제로 렌더해 찍은 것**이고, 「MyRosary World」 시안(`docs/design/world/`)의 Home 블록과 나란히 놓고 대조하기 위한 자리다.

찍은 크기는 390×844, 화소 배율 2다. 실제 폰과 같은 촘촘함으로 찍기 위한 값이며 `playwright.config.ts` 가 정한다. 사진을 찍는 시험은 `e2e/screenshots.spec.ts` 의 `W2 · …` 세 개다.

## 시안과 견줄 때 알아 둘 것 다섯

같은 화면을 시안이 렌더한 사진은 `docs/plan/world-screens/11-home-real-fonts.jpg` 다. 나란히 놓고 볼 때 **달라 보이는 자리가 다섯** 있고, 다섯 다 이유가 있다.

1. **오른쪽 위의 지역 표시가 시안에서는 테두리를 두른 단추인데 여기서는 글자뿐이다.** 지역·언어 화면이 W2 의 슬라이스 C 에서 서기 때문이다. 눌리지 않는 것이 단추처럼 보이면 고장으로 읽히므로, 단추가 될 때까지 테두리와 지구본을 뺐다.
2. **성화를 전체 화면으로 여는 단추(오른쪽 아래의 원형 단추)가 없다.** 그 화면은 W3 의 것이다.
3. **`신비 해설 →` 링크가 없다.** 그 링크가 가는 화면(오늘의 신비 · 신비 해설)은 슬라이스 B 에서 선다. 눌러도 아무 데도 가지 않는 링크를 남기지 않으려고 자리를 비웠다.
4. **`새 기도` 단추와 `초대 코드로 들어가기` 줄이 더 있다.** 시안의 홈에는 여정을 새로 만드는 자리가 아예 없는데(계정도 여정도 없는 시안이다) 이 앱에서 그 둘을 빼면 여정을 시작할 길이 사라진다.
5. **성화가 매번 다르다.** 성화 뽑기가 아직 난수라서, 같은 시험을 다시 돌리면 다른 그림이 나온다. 씨앗을 물릴 수 있게 하는 일은 결정 큐 Q-57 이 W2 로 미뤄 둔 것이고 슬라이스 C 에서 함께 들어온다. **그래서 이 다섯 장에서 성화의 내용은 대조 대상이 아니다** — 대조할 것은 그림이 아니라 배치와 글과 색이다.

## 아직 옛 어법으로 남아 있는 자리 하나

`home-again-sheet.png` 의 시트는 **밝은 한지 바탕에 먹빛 단추**로, 새 시안의 어법이 아니다. 이 저장소의 시트 부품 하나(`src/ui/Sheet.tsx`)를 시트 일곱이 함께 쓰고 있고, 그 부품을 시안의 어법으로 옮기는 일은 W2 작업 지시서 §3(결정 큐 Q-56)의 몫이라 슬라이스 A 에서 손대지 않았다. 부품 하나를 옮기면 일곱이 함께 옮겨진다.

같은 이유로 설정 화면도 아직 옛 한지 벌이다. 그 화면을 시안의 어법으로 옮기는 일은 슬라이스 C 다.

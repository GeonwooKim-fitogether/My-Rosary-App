## 어떻게 찍었나 — 그리고 사진이 시안과 다른 점 하나

시안의 렌더 엔진은 React 와 Babel 을 외부 주소(unpkg)에서 받아 오는데 이 컨테이너는 그 주소가 막혀 있다. 그래서 같은 판을 npm 에서 받아 로컬 웹 서버로 대신 내주고(`window.__resources` 표), Playwright 로 화면을 옮겨 가며 찍었다. 조작은 시안이 디버깅용으로 열어 둔 손잡이 `window.__rosary` 로 했다(`go('gallery')` · `startSession()` · `goStep(24)` 등).

**글꼴은 시안과 다르다.** 시안은 Cormorant Garamond · Lora · Noto Serif KR 을 Google Fonts 에서 받는데 그 주소도 막혀 있어, 사진의 글자는 이 컨테이너의 기본 명조·고딕으로 대신 그려졌다. 글자의 모양과 굵기는 시안을 믿고, 이 사진에서는 **배치·비율·색·묵주의 기하**만 본다.

## 번들한 글꼴로 다시 찍은 두 장 (2026-09-17, W0)

| 파일 | 무엇을 보나 |
|---|---|
| `11-home-real-fonts.jpg` | 홈 (한국 · 한국어). 제목이 Cormorant Garamond, 본문이 Lora, 한글이 Noto Serif KR 로 그려졌다 |
| `12-home-en-real-fonts.jpg` | 홈 (유럽 · 영어). 라틴 글꼴이 온전히 드러나는 화면이라 글꼴의 인상을 여기서 본다 |

W0 에서 글꼴 넷(Cormorant Garamond 400·600, Lora 400·600)을 `assets/fonts/` 에 번들하면서, **그 파일이 정말 시안이 부르던 글꼴인지**를 눈으로 확인한 사진이다. 시안은 글꼴을 Google Fonts 에서 받는데 이 컨테이너에서 그 주소가 막혀 있으므로, 브라우저의 글꼴 요청을 가로채 저장소의 TTF 파일을 대신 내주고 찍었다. 브라우저가 실제로 "loaded" 로 보고한 글꼴 셋을 확인한 뒤 찍은 것이라, 대체 글꼴로 그려진 위의 열 장과 다르다.

**이 두 장에서 함께 보이는 것 하나.** 머리의 작은 라벨(`TODAY'S MYSTERY · …`)과 링크가 강조색으로 그려지는데, 종이색 위에서 그 대비가 2.26~2.94 에 그친다. 본문 기준 4.5:1 에도 그림 요소 기준 3:1 에도 닿지 않는 값이며, 사진에서도 흐리게 읽힌다. 고칠지는 사람이 정할 일이라 결정 큐 Q-51 에 올렸다.

## 권리 — 이 사진들에 보이는 것

성화 열일곱 장의 오른쪽 아래를 모두 확인한 결과 **넷에 작가 서명이나 스톡 워터마크가 있다.** `02-mary-child.jpg` · `04-cross.jpg` · `11-prayer-rosary.jpg` 은 같은 스튜디오(Angela Gil · Velvet Whispers Studio)의 워터마크이고, `13.jpg` 는 그림 안에 붓으로 그려진 서명이다. 시안의 표에서 이미 빠져 있는 `09-color-jesus.jpg` 는 스톡 사진 워터마크가 화면 전체에 반복된다. 검증 단계까지는 그대로 쓰되 정식 출시 자산에서는 교체 대상이며(PRD D-1), 표의 `mark` 와 시험이 그 넷을 붙들고 있다.

## 이 사진이 증명하는 것과 증명하지 않는 것

- 증명하는 것: 인계본이 이 저장소 안에서 온전히 열리고, 화면 열이 모두 동작하며, 81단계 순서와 묵주 진행 방향이 이 저장소의 `spec/` 과 같다.
- 증명하지 않는 것: 실제 글꼴이 얹힌 모습, 손가락으로 고리를 돌리는 감각, 실기기에서의 소리·진동. 이 셋은 사람이 폰에서 확인해야 한다.

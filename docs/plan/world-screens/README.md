## 어떻게 찍었나 — 그리고 사진이 시안과 다른 점 하나

시안의 렌더 엔진은 React 와 Babel 을 외부 주소(unpkg)에서 받아 오는데 이 컨테이너는 그 주소가 막혀 있다. 그래서 같은 판을 npm 에서 받아 로컬 웹 서버로 대신 내주고(`window.__resources` 표), Playwright 로 화면을 옮겨 가며 찍었다. 조작은 시안이 디버깅용으로 열어 둔 손잡이 `window.__rosary` 로 했다(`go('gallery')` · `startSession()` · `goStep(24)` 등).

**글꼴은 시안과 다르다.** 시안은 Cormorant Garamond · Lora · Noto Serif KR 을 Google Fonts 에서 받는데 그 주소도 막혀 있어, 사진의 글자는 이 컨테이너의 기본 명조·고딕으로 대신 그려졌다. 글자의 모양과 굵기는 시안을 믿고, 이 사진에서는 **배치·비율·색·묵주의 기하**만 본다.

## 이 사진이 증명하는 것과 증명하지 않는 것

- 증명하는 것: 인계본이 이 저장소 안에서 온전히 열리고, 화면 열이 모두 동작하며, 81단계 순서와 묵주 진행 방향이 이 저장소의 `spec/` 과 같다.
- 증명하지 않는 것: 실제 글꼴이 얹힌 모습, 손가락으로 고리를 돌리는 감각, 실기기에서의 소리·진동. 이 셋은 사람이 폰에서 확인해야 한다.

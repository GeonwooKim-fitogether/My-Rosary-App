## 실행용 프롬프트

당신은 세계 최고 수준의 시니어 모바일 프로덕트 디자이너이자 프론트엔드 개발자입니다.

현재 제작 중인 글로벌 가톨릭 묵주기도 앱 **MyRosary World**를 분석하고, 전 세계에서 가장 세련되고 사랑받는 묵주기도 앱이 될 수 있도록 디자인과 사용 경험을 전면적으로 고도화해 주세요.

단순한 디자인 제안이나 목업으로 끝내지 말고, 현재 코드베이스를 직접 분석하여 작동하는 결과물까지 구현해 주세요.

### 1. 제품의 최우선 목표

이 앱은 일반적인 명상 앱이나 종교 콘텐츠 앱이 아닙니다.

사용자가 실제 묵주를 손에 들고 기도하는 듯한 감각과, 아름다운 성화를 감상하는 경험을 결합한 프리미엄 모바일 묵주기도 앱이어야 합니다.

핵심 감정은 다음과 같습니다.

- 고요하지만 지루하지 않음
- 경건하지만 낡아 보이지 않음
- 예술적이지만 사용하기 어렵지 않음
- 현대적이지만 가톨릭 정체성을 희석하지 않음
- 화려함보다 빛, 여백, 질감, 깊이로 감동을 줌

시각적 기준은 **가톨릭 성화 미술관 × 럭셔리 에디토리얼 × 현대적인 모바일 기도 도구**입니다.

### 2. 절대 보존해야 하는 핵심 기능

기존 기능을 디자인 과정에서 삭제하거나 단순화하지 마세요.

반드시 유지해야 할 기능:

- 완전한 묵주기도 81단계
- 성호경, 사도신경, 주님의 기도, 성모송, 영광송, 구원을 비는 기도, 성모찬송, 마침 성호경
- 환희·빛·고통·영광의 신비
- 5단 전체 기도
- 실제 구조와 같은 59알 묵주
  - 성모송 묵주알 53개
  - 주님의 기도 묵주알 6개
  - 중앙 메달
  - 십자가
- 현재 기도할 묵주알의 명확한 표시
- 완료한 묵주알의 진행 상태 표시
- 묵주 고리를 손가락으로 돌려 앞·뒤 기도로 이동
- 묵주 가운데를 눌러 다음 기도로 이동
- 묵주알 이동 시 부드러운 회전 애니메이션과 짧은 햅틱 피드백
- 기도 이어하기와 진행 상태 저장
- 음성 기도 모드
- 글자 크기 조절
- 기도 여정과 9일·54일 기도
- 성화 갤러리와 즐겨찾기
- 이미지 고정 및 변경
- 오프라인 사용 기능
- 설치 가능한 모바일 웹앱(PWA)

특히 묵주는 장식물이 아니라 앱의 핵심 입력 장치입니다. 사용자가 실제로 묵주를 돌리고 있다는 느낌을 받아야 합니다.

### 3. 이미지 경험

제공된 이미지의 유화, 임파스토, 회화적 붓 터치, 빛과 질감이 매우 중요합니다.

이미지를 단순한 카드 썸네일로 소비하지 마세요. 앱 전체의 분위기와 감정을 이끄는 핵심 요소로 사용하세요.

- 홈 화면에서 성화가 강력한 Hero 이미지로 보이게 할 것
- 기도 화면에서도 성화를 몰입형 배경으로 사용할 것
- 기도문 가독성을 위해 이미지 위에 정교한 그라데이션과 명암 마스크를 적용할 것
- 이미지의 얼굴이나 핵심 피사체가 잘리지 않도록 focal position을 관리할 것
- 앱을 새로 열 때마다 다른 작품이 나타나도록 할 것
- 같은 이미지가 연속해서 반복되지 않도록 할 것
- 한 번 시작한 기도에서는 배경 이미지가 중간에 바뀌지 않도록 할 것
- 사용자가 마음에 드는 이미지를 고정하거나 즐겨찾기 할 수 있게 할 것
- 성화만 전체 화면으로 조용히 감상할 수 있는 모드를 제공할 것
- 작은 화면에서도 기도문, 묵주, 이미지가 서로 겹치지 않도록 할 것

스톡사진, 워터마크 이미지, 저해상도 이미지, 일반적인 AI 명상 이미지는 사용하지 마세요.

### 4. 다섯 가지 지역 경험

하나의 공통 기도 엔진과 디자인 시스템을 유지하되, 아래 다섯 버전이 서로 다른 감성과 이미지를 갖도록 설계하세요.

#### 유럽

- 고전 성화, 대성당, 스테인드글라스, 촛불, 키아로스쿠로
- 아이보리, 딥 네이비, 버건디, 앤티크 골드
- 오래된 성당과 현대적인 럭셔리 편집 디자인의 조합

#### 북미

- 넓은 공간, 현대적인 성당, 자연광, 영화적인 풍경
- 다양한 인종과 공동체를 포용하는 표현
- 딥 블루, 슬레이트, 골드, 부드러운 일출빛
- 현대적이고 직관적이며 접근성이 높은 분위기

#### 남미

- 따뜻한 햇빛, 풍부한 색감, 꽃, 촛불, 공동체적 신앙
- 테라코타, 울트라마린, 금색, 짙은 녹색
- 기쁨과 생명력이 느껴지되 관광상품처럼 보이지 않게 할 것

#### 아시아

- 고요한 자연, 안개, 여백, 절제된 빛과 섬세한 질감
- 먹빛, 옥색, 따뜻한 백색, 은은한 금색
- 하나의 ‘아시아풍’으로 뭉뚱그리거나 문화적 클리셰를 사용하지 말 것

#### 한국

- 한지 질감, 절제된 단청색, 달항아리, 새벽빛과 고요한 여백
- 먹색, 미색, 청색, 옅은 적색과 금색
- 한국 가톨릭 신자의 정서와 성모 신심이 자연스럽게 느껴질 것
- 전통 요소를 과도하게 장식적으로 사용하지 말 것

국가 또는 지역적 특성은 존중과 맥락을 통해 표현하고, 국기나 뻔한 전통 문양에 의존하지 마세요.

### 5. 언어

다음 언어를 지원하고 기존 기도문을 보존하세요.

- 한국어
- 영어
- 이탈리아어
- 프랑스어
- 스페인어
- 포르투갈어
- 필리핀어

지역과 언어는 독립적으로 변경할 수 있어야 합니다.

권장 기본 언어:

- 유럽: 영어, 이탈리아어, 프랑스어
- 북미: 영어, 스페인어
- 남미: 스페인어, 포르투갈어
- 아시아: 영어, 필리핀어
- 한국: 한국어

공식 기도문을 임의로 축약하거나 현대적인 명상 문구로 바꾸지 마세요. 번역이 불확실한 경우 새로 창작하지 말고 기존 제공 문구를 유지하세요.

### 6. 핵심 화면

다음 화면을 일관된 디자인 시스템으로 완성하세요.

1. 홈
2. 오늘의 신비
3. 기도 진행 화면
4. 성화 갤러리
5. 신비 해설
6. 기도 여정
7. 설정
8. 기도 완료 화면
9. 성화 전체 화면 감상
10. 지역 및 언어 선택

가장 중요한 화면은 **기도 진행 화면**입니다.

기도 중에는 다음 정보의 위계가 명확해야 합니다.

1. 현재 묵주알
2. 현재 기도문
3. 현재 단과 진행 단계
4. 성화
5. 음성·이전·다음 조작

59알 묵주 전체를 볼 수 있어야 하며, 현재 알이 빛나고 완료한 알은 은은한 금빛으로 변해야 합니다. 고리를 직접 드래그하면 손가락을 따라 움직이고, 놓으면 해당 기도 위치로 부드럽게 정렬되어야 합니다.

### 7. 디자인 금지사항

다음과 같은 결과는 피하세요.

- 평범한 SaaS 대시보드
- 카드가 지나치게 많은 Card Soup 레이아웃
- 일반적인 수면·명상 앱처럼 보이는 디자인
- 보라색 또는 파스텔 그라데이션 남용
- 과도한 Glassmorphism
- 귀여운 캐릭터, 이모지, 클립아트
- 십자가나 묵주를 단순 장식 아이콘으로만 사용하는 방식
- 지나치게 작은 기도문
- 성화 위에 가독성 없이 텍스트를 올리는 방식
- 종교적 의미보다 시각 효과를 우선하는 연출
- 기존 기능과 저장 데이터를 삭제하는 전면 재작성

### 8. 모바일 앱 기준

모바일 앱이 가장 중요합니다.

다음 화면 너비를 우선 검증하세요.

- 320px
- 375px
- 390px
- 430px

필수 조건:

- 한 손 조작 가능
- 주요 터치 영역 최소 44px
- iPhone Safe Area 대응
- 긴 한국어·프랑스어·포르투갈어 기도문의 overflow 방지
- 묵주와 기도문이 겹치지 않을 것
- 이미지 로딩 중 레이아웃이 흔들리지 않을 것
- 저사양 스마트폰에서도 회전 애니메이션이 부드러울 것
- `prefers-reduced-motion` 접근성 지원
- 스크린리더용 현재 묵주알 및 진행 상태 안내
- 기도 중 화면이 갑자기 갱신되거나 이미지가 변경되지 않을 것

데스크톱에서도 작동해야 하지만, 데스크톱 웹페이지를 축소한 형태가 아니라 모바일 앱을 확장한 구조로 설계하세요.

### 9. 작업 방식

다음 순서로 진행하세요.

1. 현재 코드와 참고 자료를 모두 읽고 기존 기능 목록 작성
2. 현재 디자인의 장점과 문제점을 냉정하게 진단
3. 앱에 가장 적합한 디자인 방향 결정
4. 색상, 타이포그래피, 여백, 이미지 처리, 버튼, 묵주 인터랙션을 포함한 디자인 시스템 정의
5. 기존 기능과 저장 구조를 보존하면서 코드에 직접 적용
6. 5개 지역과 7개 언어에서 UI 검증
7. 모바일 화면별 스크린샷 또는 프리뷰 제공
8. 변경된 파일과 테스트 결과 보고

중간에 “어떤 방향으로 할까요?”라고 작업을 멈추지 말고, 전문가로서 가장 적합한 방향을 판단하여 완성도 높은 첫 번째 결과물을 구현하세요.

### 10. 완료 기준

다음 조건을 모두 충족해야 완료로 판단합니다.

- 첫 화면에서 3초 안에 앱의 정체성과 오늘의 기도 시작 버튼을 이해할 수 있음
- 성화가 앱의 중심으로 느껴짐
- 59알 전체 묵주가 정확히 표시됨
- 묵주를 손가락으로 실제 돌릴 수 있음
- 현재 알과 완료한 알을 즉시 구분할 수 있음
- 81단계 기도 진행과 묵주 위치가 정확히 연결됨
- 5개 지역이 같은 앱이면서도 서로 다른 정서를 가짐
- 7개 언어에서 텍스트가 잘리지 않음
- 기존 기도 기록과 이어하기가 유지됨
- 홈을 다시 열 때 이미지가 바뀌지만 기도 중에는 고정됨
- 앱 설치와 오프라인 기본 사용이 유지됨
- 단순히 ‘예쁜 종교 앱’이 아니라 다시 사용하고 싶은 프리미엄 기도 경험이 됨

마지막에는 반드시 다음 내용을 보고하세요.

- 핵심 디자인 콘셉트 한 문장
- 기존 앱에서 유지한 기능
- 새롭게 개선한 요소
- 지역별 디자인 차이
- 수정한 파일
- 실행 및 테스트 방법
- 아직 남아 있는 기술적 한계

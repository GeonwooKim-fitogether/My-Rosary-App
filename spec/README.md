# spec/ — 프레임워크와 무관한 기도 도메인 데이터

이 폴더는 어떤 프레임워크로 앱을 만들든 그대로 가져다 쓸 수 있는 **기도 도메인의 사실**만 담는다. PRD(`docs/product/06-prd.md`)를 대신하지 않고, PRD의 §1-3·FR-43과 화면 명세의 비화면 채널 상수를 **기계가 읽는 형태**로 옮긴 것이다.

| 파일 | 담는 것 | 출처 | 확정 상태 |
|---|---|---|---|
| `prayer-sequence.json` | 한 번의 묵주기도 81단계 순서 (시작 기도 9 + 단 14 × 5 + 마침 기도 2) | PRD §1-3 · FR-10 · 표준 「묵주기도 방법」 도해 (`decisions.md` 결정 7) | 확정 |
| `mysteries.json` | 신비 4종 × 5단 제목, 요일 규칙, 54일 순환 규칙 | FR-43 · 프로토타입 v4 상수 | 규칙은 확정. 제목 문구는 판본 확정(D-4) 때 다시 대조 |
| `prayers.ko.json` | 성호경·십자가에 입맞춤·사도신경·주님의 기도·성모송·영광송·구원을 비는 기도·성모찬송의 앞 절/뒷 절 | 프로토타입 v4 수록문 (십자가에 입맞춤과 성모찬송은 결정 7 이 더했다) | **미확정** — 공식 판본과 사용 권한은 PRD D-4. 사도신경과 성모찬송은 첫 문장만 있다(지어 넣지 않았다) |
| `journey-rules.md` | 여정 형식 셋, 며칠째 계산, 자리 저장, 받는 사이 공식, 진동 사전, 손 없이 조작, 조 배정, 전례 시기 | PRD §1-4·§7·§8 · FR 다수 · 06-d 화면 B | 규칙은 확정. PRD에 없는 것은 `decisions.md` Q-번호로 가리킨다 |

**원칙 하나.** 이 폴더에는 PRD에 없는 것을 지어 넣지 않는다. 비어 있어야 하는 자리(사도신경 전문, 성모찬송 전문, 판본 목록)는 비어 있다고 적어 두었다.
